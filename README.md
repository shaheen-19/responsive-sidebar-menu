# Responsive Sidebar Menu

A modern, responsive sidebar navigation menu developed using **HTML5** and **CSS3**. The project demonstrates clean UI design principles, responsive layouts, smooth animations, and modern CSS techniques without using JavaScript.

## 📖 Overview

This project features a responsive sidebar that slides in and out using the CSS checkbox technique. It includes a glassmorphism interface, interactive hover effects, Font Awesome icons, and a mobile-friendly layout.

## ✨ Features

- Responsive sidebar navigation
- Pure HTML5 and CSS3 implementation
- CSS-only toggle functionality
- Smooth transition animations
- Glassmorphism design using `backdrop-filter`
- Interactive hover effects
- Font Awesome integration
- Mobile responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
